DIETA FC — MINI-APP PER IPHONE

CONTENUTO
index.html, style.css, app.js, data.js, manifest.webmanifest, sw.js e due icone.

PUBBLICAZIONE GRATUITA CON GITHUB PAGES
1. Crea un account su github.com (se non lo hai).
2. Crea un nuovo repository PUBBLICO chiamato dieta-fc (non caricare informazioni mediche personali: il repository è pubblico).
3. Nel repository seleziona Add file > Upload files e carica TUTTI gli 8 file della cartella dieta_fc_pwa (non caricare lo ZIP).
4. Vai in Settings > Pages, sotto Build and deployment seleziona Deploy from a branch, branch main, cartella /(root), poi Save.
5. Attendi la pubblicazione. L'indirizzo sarà https://TUO-UTENTE.github.io/dieta-fc/ (sostituisci TUO-UTENTE).
6. Apri il link con Safari su iPhone. Tocca Condividi e scegli Aggiungi alla schermata Home, quindi Aggiungi. In alcune versioni di iOS, scorri il menu Condividi per trovare la voce.
7. Apri l'icona Dieta FC dalla schermata Home. Dopo una prima visita online, i file sono disponibili anche offline.

NOTA: GitHub Pages richiede che il repository sia pubblico per l'hosting gratuito con i piani ordinari. Non inserire valori glicemici o altri dati sanitari nel codice. Le spunte sono memorizzate localmente sul dispositivo.

PROVA SU COMPUTER
Per provare la PWA correttamente usa un server HTTP locale, non aprire index.html direttamente come file. Con Python installato, apri il terminale nella cartella e lancia: python -m http.server 8000 ; poi apri http://localhost:8000

DATI DI PARTENZA
Il piano è una bozza basata sulla conversazione. Purea di frutta inserita al posto dei frutti nei due spuntini; banana a colazione invariata. La cena del mercoledì contiene ancora patate dolci + pane: da confermare. I macro sono stime, non prescrizioni. Non sono incluse indicazioni sulle dosi di Creon o Apidra.
